# Fork evidence measured on the ESPN draft extension

These measurements and upstream drafts were taken with the ESPN draft
extension ([chrome-ext-bompus-espn-draft](https://github.com/bompus/chrome-ext-bompus-espn-draft))
as the pinned test checkout, from 2026-09-04 to 2026-09-15. They moved here on
2026-09-25 because their subject is this fork's retrieval, deployment and
upstream contributions, not the extension. Their query receipts stay in that
repository's `docs/agents/codegraph-query-audit.jsonl`, and links to it point
there.

| File | What it measures |
| --- | --- |
| `PLAN-codegraph-audit-and-fork-improvements.md` | Audit and fork-improvement plan (closed) |
| `PLAN-codegraph-experiments.md` | Earlier experiment plan (closed) |

| `codegraph-retrieval-repro.json` | Receipts for the retrieval reproduction |
| `upstream-drafts/` | Draft upstream issues, comments and PRs from the rules-ab runs |
